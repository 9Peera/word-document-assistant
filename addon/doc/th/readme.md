# ผู้ช่วยเอกสาร Word

* ผู้พัฒนา: Peera Pilarit
* รองรับ NVDA: 2026.1 ขึ้นไป
* Microsoft Word: Microsoft 365, Office 2021, Office 2019

ผู้ช่วยเอกสาร Word ช่วยให้นำทาง อ่าน และจัดการรายการตรวจทานใน Microsoft Word ได้โดยไม่ต้องออกจากเอกสาร
ได้แก่ คำสะกดผิด ปัญหาไวยากรณ์ ข้อคิดเห็น เชิงอรรถ endnote และการติดตามการเปลี่ยนแปลง (Track Changes)

## โหมดนำทาง

กด NVDA+Shift+F8 ในเอกสาร Word เพื่อเข้าโหมดนำทาง จะได้ยินเสียงขาขึ้นและชื่อชนิดองค์ประกอบปัจจุบัน
กด NVDA+Shift+F8 อีกครั้ง, Escape หรือ Enter เพื่อออก

ขณะนำทาง เคอร์เซอร์ของ Word จะย้ายไปที่แต่ละรายการจริง
เมื่อออกจากโหมด เคอร์เซอร์จะอยู่ที่รายการล่าสุดที่ทำงานอยู่ จึงไม่หลงตำแหน่ง

### ไปยังชนิดองค์ประกอบ

กดตัวอักษรเพื่อไปยังรายการถัดไปของชนิดนั้น กด Shift พร้อมตัวอักษรเพื่อย้อนไปรายการก่อนหน้า

|---|---|
| S | คำสะกดผิด |
| G | ปัญหาไวยากรณ์ |
| C | ข้อคิดเห็น |
| F | เชิงอรรถ |
| E | endnote |
| R | การแก้ไขที่ติดตาม (Track Changes) |
| O | หัวเรื่อง |
| U | ตาราง |
| M | รูปภาพและข้อความแสดงแทน |
| K | ลิงก์ |
| X | การอ้างอิงโยง |
| I | การอ้างอิง (citation) |
| B | บุ๊กมาร์ก |
| D | ฟิลด์ |
| L | ข้อความที่กำหนดภาษาผิด |
| A | ปัญหาการเข้าถึงได้ |
| Z | ตรวจคำภาษาไทยด้วยรายการคำแบบออฟไลน์ |

### การออกจากโหมด

| คีย์ | ผลลัพธ์ |
|---|---|
| Enter | ออกที่รายการปัจจุบัน พร้อมแก้ไขทันที คำสะกดผิดจะถูกเลือกไว้ พิมพ์เพื่อแทนที่ได้เลย สำหรับเชิงอรรถและ endnote เคอร์เซอร์จะเข้าไปอยู่ในข้อความบันทึก |
| Escape | ออกจากโหมด เคอร์เซอร์อยู่ที่รายการปัจจุบัน |
| Backspace | กลับไปตำแหน่งเดิมก่อนเข้าโหมด แล้วออกจากโหมด |
| คีย์อื่นๆ | ออกจากโหมด และคีย์นั้นทำงานตามปกติของ Word |

ตัวอักษรและตัวเลขที่ไม่มีคำสั่งจะไม่ถูกพิมพ์ลงเอกสารขณะอยู่ในโหมด แต่จะมีเสียงเตือนแทน

โหมดนี้อ่านคีย์ตามตำแหน่งปุ่ม จึงใช้ได้เหมือนกันทั้งแป้นพิมพ์ภาษาไทยและภาษาอังกฤษ

## หน้าต่างรายการ

กด Space ในโหมดนำทางเพื่อเปิดรายการทั้งหมดของชนิดปัจจุบัน

* พิมพ์ในช่องตัวกรองเพื่อแสดงเฉพาะรายการที่ตรงกัน
* รายละเอียดแต่ละส่วนอยู่ในช่องอ่านอย่างเดียวแยกกัน สำหรับข้อคิดเห็นได้แก่ ผู้เขียน, วันที่, สถานะ, ข้อความที่แสดงความคิดเห็น, ข้อคิดเห็น และการตอบกลับ
  จึงอ่านและคัดลอกแต่ละส่วนได้แยกกัน (กด Tab ไปยังช่องที่ต้องการ แล้ว Control+A และ Control+C)
* ปุ่ม ไปยัง ย้ายเคอร์เซอร์ไปที่รายการนั้น โดยยังอยู่ในโหมดนำทาง
* ปุ่ม คำสั่ง เปิดคำสั่งของรายการ กดปุ่ม Applications ที่รายการก็ได้เช่นกัน
* ปุ่ม คัดลอกข้อความ คัดลอกข้อความหลัก ปุ่ม คัดลอกรายละเอียดทั้งหมด คัดลอกทุกช่องพร้อมชื่อหัวข้อ

## คำสั่งของแต่ละชนิด

| ชนิด | คำสั่ง |
|---|---|
| คำสะกดผิด | แทนที่ด้วยคำแนะนำ, พิมพ์คำที่ใช้แทน, คัดลอก |
| ปัญหาไวยากรณ์ | คัดลอก |
| ข้อคิดเห็น | ตอบกลับ, แก้ไข, ทำเครื่องหมายว่าแก้ไขแล้วหรือเปิดใหม่, ลบ, คัดลอกข้อคิดเห็นหรือข้อความที่แสดงความคิดเห็น, เพิ่มข้อคิดเห็นใหม่ที่ตำแหน่งเดิม |
| เชิงอรรถและ endnote | แก้ไขข้อความบันทึก, ลบ, แปลงระหว่างเชิงอรรถกับ endnote, แทรกบันทึกใหม่ที่ตำแหน่งเดิม, คัดลอก |
| การแก้ไขที่ติดตาม | ยอมรับ, ปฏิเสธ, ยอมรับหรือปฏิเสธทั้งหมดของผู้เขียนคนเดียวกัน, ยอมรับหรือปฏิเสธทั้งหมดในเอกสาร, คัดลอก |

"ตำแหน่งเดิม" คือตำแหน่งเคอร์เซอร์หรือข้อความที่เลือกไว้ตอนกด NVDA+Shift+F8
การเปลี่ยนแปลงแต่ละครั้งเป็นการเลิกทำ (undo) หนึ่งขั้นของ Word กด Control+Z เพื่อย้อนกลับได้

## คำแนะนำจาก AI (เลือกใช้ได้)

AI ช่วยแนะนำการแก้คำสะกดผิดและถ้อยคำ เสนอคำที่ถูกต้องสำหรับคำสะกดผิด และร่างคำตอบข้อคิดเห็น
**AI ทำหน้าที่แนะนำเท่านั้น เอกสารจะไม่เปลี่ยนแปลงจนกว่าผู้ใช้จะเลือกคำแนะนำเอง**

* กด W ในโหมดนำทางเพื่อตรวจย่อหน้าปัจจุบัน หรือ Shift+W เพื่อตรวจข้อความที่เลือกไว้ก่อนกด NVDA+Shift+F8
  หน้าต่างจะแสดงแต่ละรายการเป็น "ข้อความเดิม เป็น คำแนะนำ" พร้อมช่องข้อความเดิม คำแนะนำ และเหตุผลแยกกัน
  กด Space เพื่อทำเครื่องหมายรายการที่ต้องการ แล้วกด ใช้รายการที่เลือก การแก้ไขทั้งหมดเป็นการเลิกทำ (undo) หนึ่งขั้น
* ที่คำสะกดผิด เมนูคำสั่งมี "คำแนะนำจาก AI..." เลือกคำที่ต้องการเพื่อแทนที่
* ที่ข้อคิดเห็น เมนูคำสั่งมี "ร่างคำตอบด้วย AI..." เลือกร่าง แก้ไขได้ แล้วยืนยันเพื่อส่งคำตอบ

เปิดใช้ AI ได้ที่การตั้งค่า แล้วเลือกบริการ:

| บริการ | ค่าใช้จ่าย | ข้อความถูกส่งไปที่ |
|---|---|---|
| Google Gemini (เลือกโมเดลอัตโนมัติเมื่อเว้นช่องโมเดลว่าง) | ใช้ฟรีได้ด้วย API key ที่ขอฟรีจาก Google AI Studio | Google ซึ่งในแบบฟรีอาจนำข้อมูลไปใช้ปรับปรุงผลิตภัณฑ์ |
| บริการที่รองรับรูปแบบ OpenAI | ขึ้นกับบริการ (หลายบริการมีแบบฟรี) | บริการนั้น |
| Anthropic Claude | เสียเงินตามการใช้งาน สร้าง key และตั้งค่าการชำระเงินที่ console.anthropic.com | Anthropic |
| OpenAI | เสียเงินตามการใช้งาน สร้าง key และตั้งค่าการชำระเงินที่ platform.openai.com | OpenAI |
| Ollama ในเครื่องนี้ | ฟรี | อยู่ในเครื่องนี้ แนะนำสำหรับเอกสารลับ |

### การขอ API key ฟรี

กด NVDA+Control+Shift+F8 ได้ทุกที่ (หรือปุ่ม ขอหรืออัปเดต API key ในการตั้งค่า) เพื่อเปิดหน้าตั้งค่า AI
หน้าต่างนี้จะเปิดเองเมื่อใช้ AI ครั้งแรก และทุกครั้งที่ key หายไปหรือใช้ไม่ได้ จึงอัปเดต key ได้ตลอดเวลา

1. กดปุ่ม ขอ API key ฟรี หน้า Google AI Studio จะเปิดในเบราว์เซอร์
2. ลงชื่อเข้าใช้ด้วยบัญชี Google ของตัวเอง สร้าง key แล้วคัดลอก
3. กลับมาที่หน้าต่างตั้งค่า ระบบจะพบ key ในคลิปบอร์ด ทดสอบ และใส่ให้เอง (หรือกดปุ่ม วาง key จากคลิปบอร์ดและทดสอบ)
4. กดปุ่ม บันทึกและเปิดใช้ AI

ส่วนเสริมขอ key แทนผู้ใช้ไม่ได้ เพราะ key ผูกกับบัญชีของผู้ใช้แต่ละคน และ key ที่พบบนอินเทอร์เน็ตเป็นของผู้อื่น

สำหรับ Ollama ให้เลือกในหน้าต่าง กดปุ่ม ดาวน์โหลด Ollama ฟรี แล้วกด ค้นหา Ollama ในเครื่องนี้ ระบบจะแสดงโมเดลที่ติดตั้งไว้และเลือกให้ ไม่ต้องใช้ key

ก่อนส่งข้อความไปยังบริการออนไลน์ครั้งแรก ส่วนเสริมจะถามความยินยอมก่อน
API key เก็บไว้ในการตั้งค่า NVDA ของเครื่องนี้ โดยเข้ารหัสไว้สำหรับบัญชีผู้ใช้ Windows ของคุณ

## การเข้าถึงได้ของเอกสาร

กด A ในโหมดนำทางเพื่อไปยังปัญหาการเข้าถึงได้ทีละรายการ กด Space เพื่อดูทั้งหมด และกดปุ่ม Applications เพื่อเลือกวิธีแก้ของแต่ละรายการ

| ปัญหา | วิธีแก้ |
|---|---|
| รูปภาพไม่มีข้อความแสดงแทน | พิมพ์เอง ให้ AI เขียนคำอธิบายแบบสั้นหรือละเอียดให้ตรวจ หรือทำเครื่องหมายเป็นภาพตกแต่ง |
| ตารางไม่มีแถวหัวตาราง | กำหนดแถวแรกเป็นแถวหัวตาราง |
| หัวเรื่องข้ามระดับ | เปลี่ยนเป็นระดับที่ถูกต้อง |
| ใช้ย่อหน้าว่างเว้นระยะ | ลบออกและใช้ระยะหลังย่อหน้าแทน |
| ข้อความลิงก์อย่าง คลิกที่นี่ | เปลี่ยนข้อความลิงก์ |
| เอกสารไม่มีชื่อเรื่อง | ตั้งชื่อเรื่อง (แนะนำหัวเรื่องแรกให้) |
| เอกสารยาวแต่ไม่มีหัวเรื่อง | จัดรูปแบบเอกสารด้วย AI |
| ข้อความกำหนดภาษาผิด | กำหนดคำไทยเป็นไทยและคำอังกฤษเป็นอังกฤษ |

M แสดงรูปภาพทั้งหมดพร้อมข้อความแสดงแทน AI จะอ่านรูปภาพจริง (PNG, JPEG, GIF, BMP, TIFF ส่วนภาพวาดอย่าง EMF ต้องบันทึกเป็นรูปภาพก่อน) ร่วมกับข้อความรอบรูป แล้วให้ผู้ใช้แก้ไขคำอธิบายก่อนบันทึก
L แสดงย่อหน้าที่กำหนดภาษาผิด ซึ่งทำให้ตรวจคำผิดภาษาไทยไม่ได้และ NVDA ใช้เสียงผิด มีคำสั่งแก้ทั้งเอกสารในครั้งเดียว

| I การอ้างอิง | แทรกการอ้างอิงจากแหล่งอ้างอิงในเอกสารหรือแหล่งใหม่ เพิ่มแหล่งอ้างอิง แทรกหรืออัปเดตบรรณานุกรม เปลี่ยนรูปแบบการอ้างอิง |

## เครื่องมือ AI

กด V ในโหมดนำทาง การสรุปและการตรวจความสอดคล้องใช้ข้อความที่เลือกไว้ก่อนกด NVDA+Shift+F8 หรือทั้งเอกสาร ส่วนการเรียบเรียงใหม่และการแปลใช้ข้อความที่เลือกหรือย่อหน้าปัจจุบัน

* สรุป: แบบสั้น ทีละตอน หรือประเด็นสำคัญพร้อมวันที่และสิ่งที่ต้องดำเนินการ
* เรียบเรียงใหม่เป็นภาษาราชการ ให้สุภาพขึ้น กระชับขึ้น หรือเป็นภาษาง่าย หรือแก้เฉพาะคำผิดและไวยากรณ์
* แปลเป็นภาษาอังกฤษหรือภาษาไทย
* สรุปข้อคิดเห็นทั้งหมด พร้อมเรื่องที่ยังไม่ได้แก้
* ตรวจความสอดคล้อง: การสะกด เลขไทยกับเลขอารบิก ปี วันที่ และลำดับเลข

ผลการเรียบเรียงใหม่และการแปลจะแสดงเทียบกับข้อความเดิม แก้ไขข้อความใหม่ได้ แล้วเลือกแทนที่ข้อความเดิม แทรกต่อจากข้อความเดิม (สำหรับการแปล) คัดลอก หรือปิดโดยไม่เปลี่ยนแปลง

## เครื่องมือภาษาไทย

กด Y ในโหมดนำทาง ใช้กับข้อความที่เลือกหรือทั้งเอกสาร:

* เลขอารบิกเป็นเลขไทย และกลับกัน เมนูจะบอกว่ามีตัวเลขที่จะเปลี่ยนกี่ตัว
* ปีที่เขียนพร้อม ค.ศ. เป็น พ.ศ. (บวก 543) และกลับกัน เปลี่ยนเฉพาะปีที่เขียนพร้อมศักราช ตัวเลขอื่นจึงไม่ถูกเปลี่ยน

แต่ละเครื่องมือเป็นการเลิกทำหนึ่งขั้น

## ตรวจคำภาษาไทย (ออฟไลน์)

กด Z ในโหมดนำทาง ใช้ได้โดยไม่ต้องใช้ AI หรืออินเทอร์เน็ต ด้วยรายการคำแบบเปิด:

* **คำที่มักเขียนผิด** เช่น อนุญาติ อีเมล์ นะค่ะ พร้อมคำที่ถูกต้อง ส่วนเสริมมีรายการเริ่มต้นประมาณ 65 คำ ซึ่งเขียนขึ้นเองจากตัวสะกดตามราชบัณฑิตยสถานที่รู้จักกันทั่วไป
* **คำที่ไม่มีในรายการคำ** พร้อมคำแนะนำที่ต่างกันหนึ่งตัวอักษรหรือเครื่องหมาย หรือคำเต็มเมื่อพิมพ์ไม่ครบ (คอมพิวเตอ: คอมพิวเตอร์) ชื่อที่ตามหลัง นาย นาง คุณ ดร. และคำนำหน้าอื่นๆ จะไม่ถูกรายงาน ปิดส่วนนี้ได้ในการตั้งค่า

คำสั่ง: แทนที่ด้วยคำแนะนำ แทนที่ทุกแห่ง พิมพ์คำที่ใช้แทน เพิ่มคำในรายการคำของฉัน ข้ามจนกว่าจะเริ่ม NVDA ใหม่ ค้นในเว็บไซต์พจนานุกรมราชบัณฑิตยสถาน (คัดลอกคำไว้ให้) และอัปเดตรายการคำ

### รายการคำ

| รายการ | สัญญาอนุญาต | การใช้งาน |
|---|---|---|
| รายการคำภาษาไทยของ PyThaiNLP (62,000 คำ) | CC0 1.0 | มีมาในส่วนเสริม และดาวน์โหลดรุ่นใหม่ได้ |
| พจนานุกรมไทยของ LibreOffice (NECTEC LEXiTRON, 50,000 คำ) | LGPL | ดาวน์โหลดเมื่อเปิดใช้ในการตั้งค่า |
| คำที่มักเขียนผิดของส่วนเสริม | GPL v2 | มีมาในส่วนเสริม |
| รายการคำของฉัน รายการคำผิดของฉัน | ของผู้ใช้ | ไฟล์ในโฟลเดอร์การตั้งค่า NVDA เปิดได้จากหน้าการตั้งค่า |
| รายการคำที่มักเขียนผิดขององค์กร | ขององค์กร | ดาวน์โหลดจากที่อยู่ที่ตั้งไว้ในการตั้งค่า เช่น ไฟล์บนเว็บไซต์หรือ GitHub ขององค์กร |

พจนานุกรมราชบัณฑิตยสถานไม่ได้เผยแพร่เป็นข้อมูลเปิดและมีลิขสิทธิ์ ส่วนเสริมจึงไม่ดาวน์โหลดข้อมูลนั้น แต่มีคำสั่งเปิดเว็บไซต์ของพจนานุกรมให้ค้นแทน
รายการคำของ PyThaiNLP เก็บมาจากข้อความจริง จึงมีคำที่มักเขียนผิดปนอยู่ ส่วนเสริมจะตัดคำผิดทุกคำที่อยู่ในรายการคำผิดออกก่อนใช้งาน

### รายการคำรุ่นใหม่

สัปดาห์ละครั้ง หลังเปิด NVDA หนึ่งนาที ส่วนเสริมจะถามเว็บไซต์ของรายการคำว่ามีรุ่นใหม่หรือไม่ (ส่งคำขอเพียงส่วนหัวขนาดเล็ก)
ถ้ามี จะแจ้งให้ทราบ แล้วอัปเดตได้ที่เมนู NVDA > เครื่องมือ > อัปเดตรายการคำภาษาไทย ที่เมนูคำสั่งของ Z หรือปุ่ม อัปเดตรายการคำตอนนี้ ในการตั้งค่า และตั้งให้ดาวน์โหลดอัตโนมัติได้
ไฟล์ที่ดาวน์โหลดมาจะถูกใช้เฉพาะเมื่อเป็นรายการคำภาษาไทยจริงเท่านั้น

## จัดรูปแบบเอกสารด้วย AI

กด J ในโหมดนำทาง

1. หน้าต่างจะแสดงรายการรูปแบบ AI อ่านต้นเอกสารแล้วแนะนำรูปแบบที่เหมาะสม เปลี่ยนเป็นรูปแบบอื่นได้
2. เลือกจัดทั้งเอกสาร หรือเฉพาะข้อความที่เลือกไว้ก่อนกด NVDA+Shift+F8 และเลือกว่าจะตั้งกระดาษและระยะขอบ แบบอักษร และลบย่อหน้าว่างที่ใช้เว้นระยะหรือไม่
3. กดปุ่ม วิเคราะห์และดูตัวอย่าง AI จะระบุหน้าที่ของแต่ละย่อหน้า เช่น เรื่อง เรียน เนื้อความ คำลงท้าย ลงชื่อ หัวเรื่อง **ถ้อยคำในเอกสารจะไม่ถูกเปลี่ยน**
4. หน้าตัวอย่างแสดงทุกย่อหน้าพร้อมหน้าที่ แก้หน้าที่ของย่อหน้าใดก็ได้ที่ช่อง หน้าที่ของย่อหน้าที่เลือก
5. กดปุ่ม จัดรูปแบบเลย การจัดรูปแบบทั้งหมดเป็นการเลิกทำหนึ่งขั้น กด Control+Z เพื่อย้อนกลับ

| รูปแบบ | ใช้กับ |
|---|---|
| หนังสือราชการภายนอก | ที่ ส่วนราชการ วันที่ เรื่อง เรียน อ้างถึง สิ่งที่ส่งมาด้วย เนื้อความ คำลงท้าย ลงชื่อ ส่วนราชการเจ้าของเรื่อง |
| บันทึกข้อความ | หนังสือภายใน |
| ประกาศ / คำสั่ง | ประกาศ คำสั่ง |
| จดหมายทางการ / ธุรกิจ | จดหมายถึงบริษัทหรือองค์กร |
| จดหมายทั่วไป | จดหมายส่วนตัวหรือไม่เป็นทางการ |
| รายงานทางการ | รายงานที่ใช้หัวเรื่องจริงของ Word |
| บทความ | บทความ บล็อก |
| บทความวิชาการ | บทคัดย่อ คำสำคัญ หัวเรื่อง คำบรรยายภาพ บรรณานุกรม |
| รายงานการประชุม | ระเบียบวาระเป็นหัวเรื่อง |
| เอกสารอ่านง่ายและเข้าถึงได้ | ชิดซ้าย ตัวใหญ่ หัวเรื่องจริง ไม่มีบรรทัดว่าง |

รายการลำดับเลขยังคงลำดับเลขเดิม และย่อหน้าในตารางจะไม่ถูกเปลี่ยนการเยื้อง
ค่าระยะของรูปแบบราชการอิงตามแนวปฏิบัติทั่วไป ควรตรวจกับระเบียบขององค์กรอีกครั้ง และแก้ค่าได้ในไฟล์ presets.py

## ความเป็นส่วนตัว

ส่วนเสริมใช้อินเทอร์เน็ตเฉพาะกรณีต่อไปนี้:

* **ความสามารถด้าน AI เฉพาะเมื่อเปิดใช้ AI** ข้อความที่ตรวจ เรียบเรียงใหม่ แปล หรือสรุป และรูปภาพที่ให้ AI อธิบาย จะถูกส่งไปยังบริการ AI ที่เลือก (Google Gemini, Anthropic Claude, OpenAI, บริการที่รองรับรูปแบบ OpenAI หรือ Ollama ซึ่งทำงานในเครื่อง) ส่วนเสริมจะถามก่อนส่งข้อความไปบริการออนไลน์ครั้งแรก บริการแบบฟรีอาจนำข้อมูลไปใช้ปรับปรุงบริการ
* **รายการคำภาษาไทย** สัปดาห์ละครั้ง ส่วนเสริมจะถาม GitHub (และที่อยู่ขององค์กรถ้าตั้งไว้) ว่ามีรายการคำรุ่นใหม่หรือไม่ โดยไม่ส่งข้อความในเอกสาร และดาวน์โหลดเฉพาะเมื่อผู้ใช้ยืนยัน หรือเมื่อตั้งให้ดาวน์โหลดอัตโนมัติ ปิดการตรวจรายสัปดาห์ได้ในการตั้งค่า
* **ลิงก์ที่เปิด** และเว็บไซต์พจนานุกรมราชบัณฑิตยสถาน เฉพาะเมื่อผู้ใช้เลือกเอง

API key เก็บในการตั้งค่า NVDA โดยเข้ารหัสไว้สำหรับบัญชีผู้ใช้ Windows ส่วนเสริมไม่เก็บข้อมูลการใช้งาน

## การตั้งค่า

เมนู NVDA, ตั้งค่า (Preferences), การตั้งค่า (Settings), ผู้ช่วยเอกสาร Word:

* เล่นเสียงเมื่อเข้า ออกโหมดนำทาง และเมื่อวนกลับ
* รายงานลำดับรายการ เช่น 3 จาก 12
* รายงานผู้เขียนและวันที่ของข้อคิดเห็นและการแก้ไข
* อ่านข้อความรอบคำที่สะกดผิด และจำนวนอักขระแต่ละด้าน
* จำนวนรายการสูงสุดที่รวบรวมต่อชนิด (สำหรับเอกสารที่ยาวมาก)
* คำแนะนำจาก AI: เปิดหรือปิด, บริการ, API key, ที่อยู่บริการ, โมเดล, ภาษาของเอกสาร และปุ่มทดสอบการเชื่อมต่อ

เปลี่ยนคีย์ NVDA+Shift+F8 ได้ที่ ท่าทางการป้อนข้อมูล (Input Gestures) หมวด ผู้ช่วยเอกสาร Word

## ข้อควรทราบ

* การนำทางครอบคลุมเนื้อหาหลักของเอกสาร
* ใน Microsoft 365 รุ่นใหม่ คำแนะนำไวยากรณ์บางส่วนแสดงเฉพาะในแผง Editor และไม่ได้ส่งให้ส่วนเสริม
* เอกสารที่เปิดในมุมมองที่ได้รับการป้องกัน (Protected View) ต้องเปิดใช้งานการแก้ไขก่อน
